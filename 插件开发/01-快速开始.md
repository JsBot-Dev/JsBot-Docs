# 01 · 快速开始

## 插件是什么

插件是 JsBot 的功能单元,是一个继承 `Plugin` 的类。类上的方法用装饰器标注为处理器,框架负责注册与注销。

## 目录约定

业务插件统一放在 `src/plugins/` 下,一个插件一个文件(或一个目录):

```
src/plugins/
  index.ts       # 内置插件登记表
  ping.ts        # PingPlugin
  stats/         # 复杂插件可拆成目录
    index.ts
    data.ts
```

## 最小插件

```ts
// src/plugins/ping.ts
import { Plugin, Command } from '../core';

export class PingPlugin extends Plugin {
    @Command('ping')
    ping(ctx) {
        ctx.reply('pong');
    }
}
```

- `Command('ping')` 注册命令,用户在群里或私聊发送 `/ping` 时触发(默认前缀 `/`,见 [02-装饰器](02-装饰器.md))
- 处理器参数 `ctx` 是事件上下文,`ctx.reply()` 自动按事件类型(群聊/私聊)回复

## 登记插件

### 方式一:内置插件表(推荐)

在 `src/plugins/index.ts` 中加入类,`main.ts` 会自动装载:

```ts
// src/plugins/index.ts
import type { JsBot } from '../core/bot';
import type { Plugin } from '../core/plugin';
import { PingPlugin } from './ping';

export const builtinPlugins: Array<new (bot: JsBot) => Plugin> = [PingPlugin];
```

> 注意:`builtinPlugins` 数组顺序即插件注册顺序,中间件按此顺序生效。

### 方式二:手动注册

不登记到插件表,直接在 `src/main.ts` 挂载:

```ts
import { PingPlugin } from './plugins/ping';
import { HelpPlugin } from './plugins/help';

bot.use(PingPlugin);
bot.use(HelpPlugin);
```

两种方式可混用,`bot.use()` 支持链式调用。

## 运行与调试

```bash
npm run dev   # tsx watch 热重载,改代码自动重启
```

用真实 OneBot 实现(如 go-cqhttp、NapCat)连到 `BaseUrl` 后,即可在聊天里发送 `/ping` 验证。

## 处理器方法签名速查

| 装饰器           | 处理器参数                                        |
| ---------------- | ------------------------------------------------- |
| `@Command`       | `(event, ctx, match)`                             |
| 事件装饰器       | `(event, ctx)`                                    |
| `@OnMiddleware`  | `(event, ctx, next)`                              |

详情见 [02-装饰器](02-装饰器.md)。
